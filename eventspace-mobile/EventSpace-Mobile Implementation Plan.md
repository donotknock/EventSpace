# EventSpace Mobile Companion: Implementation Plan

## Overview
A lightweight, mobile-first companion application designed for "Quick Capture", seamless pairing, and on-the-go Schedule tracking. It interfaces directly with the self-hosted EventSpace Unraid API.

## Technical Stack
* **Framework:** React 19 + Vite + TypeScript (matching the web stack for code & token reuse).
* **Native Runtime:** Capacitor (by Ionic) for iOS/Android packaging.
* **Styling:** Tailwind CSS + Lucide Icons + custom mobile design system (touch targets >= 44px, safe area padding, haptic feedback simulation, dark/light theme).
* **Native Plugins:** `@capacitor/camera`, `@capacitor/filesystem`, `@capacitor/preferences`, `@capacitor/core`.

---

## Phase 1: Foundation, Pairing & API Connectivity
* **Scaffolding:** 
  - Initialize Vite React SPA with TypeScript.
  - Install Capacitor CLI and Core (`@capacitor/core`, `@capacitor/cli`, `@capacitor/preferences`, `@capacitor/camera`).
  - Configure Tailwind CSS with mobile safe-area helpers and typography tokens matching EventSpace.
* **Pairing & Environment Configuration (Updated for Web App Settings Integration):**
  - **Auto-Pairing via QR Code / Camera Scan / Paste:**
    - Support scanning or pasting the pairing payload generated by the web app's Settings modal (`Mobile Companion App` tab).
    - Also support camera-based QR code scanning / photo upload decoder using jsQR / native camera.
  - **PIN + IP Pairing:**
    - Instant pair flow: Host address (defaults to local network address `http://192.168.1.150:3001` or auto-detected host) + 4-to-8 character Pairing PIN (`EVSP-9482`).
    - Test connection against `/api/companion/pair` and `/api/health`.
  - **Persistent Storage:**
    - Store the server URL, PIN, and paired state locally using `@capacitor/preferences` (with local storage fallback).
    - Provide an in-app "Re-pair / Server Settings" drawer to disconnect or switch servers.
* **CORS & Backend Prep:**
  - Configured Express backend CORS to permit Capacitor origins (`capacitor://localhost`, `http://localhost`, `*`) with `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `OPTIONS`.
  - Added universal toggle endpoint `/api/tasks/:id/toggle` for mobile tasks/subtasks/checklists.

---

## Phase 2: The Agenda View (Primary Mobile Screen)
* **Schedule Fetching:**
  - Consume `/api/tasks/agenda` and `/api/events` to render a chronological feed of upcoming tasks, sub-tasks, chasers, and overarching checklists.
  - Pull-to-refresh and auto-revalidation upon connection or tab focus.
* **Mobile-First UI Design:**
  - Replicate the "breathing room" calendar UI (abbreviated Day stacked on top, large Date number on bottom).
  - Categorized task cards with colored badges matching EventSpace block brands (Audio: Purple, Task: Blue, Chaser: Amber, Info: Emerald, Picture: Rose).
  - Department and Priority badges (`High`, `Med`, `Low`).
  - Event filter chips (filter by all events or focus on a specific active event).
* **Interactive Task Execution:**
  - Instant tap-to-complete checkboxes with optimistic local state updates and background `PATCH` sync to `/api/tasks/:id/toggle`.
  - Support completing top-level tasks, subtasks, and overarching checklist items.
  - Clear visual distinction for completed items (strikethrough, muted opacity).

---

## Phase 3: Quick Capture Interface (The Floating Action Button)
* A persistent, elevated FAB with rapid action drawer:
  - **Photo Capture:** `@capacitor/camera` capture with direct base64 upload to `/api/events/:eventId/nodes` as a `PictureNode`.
  - **Quick Voice / Audio Note:** Audio memo recording posted as an `AudioNode`.
  - **Quick Task / Field Note:** Fast modal for rapid on-site note and task logging.

---

## Phase 4: Native Build & Deployment
* Run `npx cap add ios` and `npx cap add android`.
* Configure `capacitor.config.ts` with bundle identifier `com.eventspace.companion`.
* Setup mobile icons, splash assets, and safe-area viewport styling.
